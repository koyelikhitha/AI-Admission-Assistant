# AI Student Admission Assistant

## Description
AI Student Admission Assistant is a Python-based chatbot that helps students by answering admission-related queries such as courses, fees, eligibility, scholarships, hostel facilities, placements, contact details, and campus information.

## Technologies Used
- Python
- JSON
- difflib
- Random
- Regex
- Datetime

## Features
- NLP Text Preprocessing
- Keyword Matching
- Similarity Matching using difflib
- Random Responses
- Time-based Greetings
- Typing Animation
- Chat History
- Unknown Question Logging
- Conversation Counter
- Context-aware Responses
